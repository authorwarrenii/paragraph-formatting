Drop Cap Editor
A minimal, full-screen HTML5 text editor that automatically styles your writing with an elegant drop cap on the very first letter. It handles layout logic natively using modern CSS pseudoclasses, keeping subsequent paragraphs perfectly indented for a clean, editorial look.

Features
✓Instant Drop Cap: The first letter automatically transforms as you type.
✓Smart Layouts: Auto-indents subsequent paragraphs while keeping the lead paragraph flush.
✓Distraction-Free: Pure, full-screen UI styled with sleek, modern accent colors.
✓One-Click Export: A built-in button instantly copies your raw text to the clipboard.
✓Zero Dependencies: Built entirely with a single file of raw HTML, CSS, and vanilla JavaScript.
